# NOVA Engine

Модульная CMS и платформа интернет-магазинов и маркетплейсов на JavaScript.

## Состав
- `apps/storefront` — Vue 3 витрина, порт 5173
- `apps/admin` — Vue 3 административная панель, порт 5174
- `apps/api` — Fastify REST API, порт 3001
- PostgreSQL 17 — хранение каталога

## Первый запуск на Windows
Понадобятся Node.js 22+, npm и Docker Desktop (с запущенным Docker Engine).

1. `git clone https://github.com/maxx52/nova-engine.git`
2. `cd nova-engine`
3. `copy .env.example .env` (в PowerShell: `Copy-Item .env.example .env`)
4. В `.env` **обязательно замените** `ADMIN_API_KEY` на собственный случайный секрет длиной не менее 16 символов. Учётные данные базы в примере предназначены только для локальной разработки.
5. `docker compose up -d`
6. `npm install`
7. `npm run dev:all`

Откройте:
- Витрина: http://localhost:5173
- Администратор: http://localhost:5174
- Проверка API: http://localhost:3001/health

В NOVA Admin нажмите **«🔑 Ключ API»** и вставьте тот же `ADMIN_API_KEY`, который записан в `.env`. Ключ сохраняется в sessionStorage браузера. Не используйте этот способ для публично доступной админ-панели.

Для остановки: `Ctrl+C` в терминале разработки и `docker compose down` для базы. Команда `docker compose down -v` **удалит данные PostgreSQL**.

## Важные ограничения
- Текущая версия предназначена **только для локальной разработки**, публичный запуск запрещён до реализации надёжной авторизации, разграничения прав, HTTPS, аудита и защиты API.
- Товары сохраняются в PostgreSQL. Витрина читает их при загрузке страницы.
- Оформление заказов, реальные платежи и аккаунты пока отсутствуют.
- При первом запуске с пустой таблицей добавляются шесть демонстрационных товаров.
- Для production нужны миграции БД, безопасное хранение секретов и резервное копирование.
