# NOVA Engine 0.22.0

- Несколько пользователей админки с ролями владельца, администратора, редактора и менеджера; права проверяются сервером.
- Создание учётных записей, изменение роли и блокировка с завершением прежних сеансов.
- Двухфакторный вход через приложение-аутентификатор (TOTP), защита от повторного использования кода и десять одноразовых резервных кодов.
- Журнал входов и действий без записи паролей, ключей и содержимого запросов.
- Новый раздел «Доступ и безопасность» и меню с учётом роли.

При обновлении существующая учётная запись сохраняется и получает роль владельца. Двухфакторный вход включается каждым пользователем самостоятельно. До обновления создайте полную резервную копию, включая конфигурацию `ADMIN_API_KEY`.

Руководство: [Доступ и безопасность](../ACCESS.md).
