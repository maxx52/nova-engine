# NOVA Engine 0.23.1

SEO-возможности 0.23: метатеги страниц, товаров и статей, sitemap.xml, robots.txt, HTTP-редиректы и Schema.org JSON-LD.

- Добавление и удаление редиректов сохраняет несохранённые SEO-настройки в соседней форме.
- Браузерная проверка отдельно подтверждает смену метаданных при клиентском переходе в карточку товара.

Для существующего nginx/VDS требуется однократно направить публичные страницы в API. Обновление приложения не изменяет конфигурацию nginx. См. [руководство SEO](../SEO.md).
