# NOVA Engine 0.22.1

- После завершения обновления или восстановления открытый раздел «Обновления и копии» загружает свежую админку. Во время установки страница не перезагружается.
- Если пользователь работает в другом разделе, при следующем ответе API появляется уведомление о новой версии с кнопкой обновления. Несохранённая работа не прерывается автоматической перезагрузкой.
- Статус различает версию установленных файлов и запущенного API. Версия от службы обновления больше не подменяет версию API.
- Защита от циклической перезагрузки при устаревшем HTML в кеше. Адрес повторной загрузки содержит номер версии.

При обновлении с 0.22.0 и более ранних версий один раз обновите вкладку админки через Ctrl+F5: уже открытый старый код ещё не содержит нового механизма.
