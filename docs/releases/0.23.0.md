# NOVA Engine 0.23.0

- SEO-поля страниц, товаров и статей: title, description, canonical, изображение Open Graph, noindex/nofollow.
- Общие настройки SEO, индексации и robots.txt; отдельные метатеги главной, каталога и блога.
- Динамические sitemap.xml и сегментированные карты только для опубликованных индексируемых адресов.
- HTTP-редиректы 301/302/307/308 с защитой от циклов и служебных адресов.
- Автоматическая Schema.org JSON-LD разметка товаров, предложений, статей, сайта и хлебных крошек.
- Индивидуальные метатеги и текст в исходном HTML, HTTP 404 для отсутствующих страниц, обновление метаданных при SPA-переходах.

**Для существующего nginx/VDS требуется однократное подключение публичных страниц к API.** Обычное обновление приложения не меняет nginx. Актуальная Docker-конфигурация уже содержит маршрутизацию.

Руководство: [docs/SEO.md](../SEO.md).
