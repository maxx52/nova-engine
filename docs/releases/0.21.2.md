# NOVA Engine 0.21.2 — права публичных сборок при обновлении и восстановлении

Исправлены права HTML и каталогов статики при закрытом umask менеджера: секретные копии остаются приватными, а опубликованные интерфейсы доступны веб-серверу. Перед завершением обслуживания дополнительно проверяются index.html, admin/index.html и файлы сборки.

Добавлены проверки установки и восстановления с umask 0077. Сохранены исправление запуска подготовки через ограниченную systemd-службу из 0.21.1, полные проверяемые копии, расписание, контроль пакета и автоматический откат.

Обновление доступно с NOVA 0.20.0. API тем и протокол менеджера остаются версии 1. Администратору сервера нужно обновить отдельную службу `agent.py` до кода этого релиза перед установкой; пакет сайта намеренно не меняет привилегированный менеджер.

Руководство: `docs/UPDATES.md`. Релизы 0.21.0 и 0.21.1 сохранены без изменения assets; для новой установки службы используйте 0.21.2.
