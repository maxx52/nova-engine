# NOVA Engine 0.25.0

Редактор страниц получил перетаскивание блоков, предпросмотр и библиотеку секций. Перенос данных теперь доступен из админки с обязательной предварительной проверкой.

- Перетаскивание мышью и на сенсорном экране, кнопки перемещения для клавиатуры.
- Общая библиотека до 200 секций: вставка независимых копий без публикации страницы.
- Предпросмотр несохранённой страницы в iframe шириной 390/768/1280 px. Формы и переходы отключены, код запускается только по отдельному флажку в песочнице.
- Экспорт JSON товаров, покупателей, страниц и статей, включая варианты, SEO и секции; выгрузка разбивается на ограниченные части.
- Импорт JSON и CSV товаров/покупателей с проверкой полей, дублей, изображений и форм, просмотром действий и изменяемых полей.
- Только добавление либо обновление совпадений по артикулу, телефону и slug. Новые записи по умолчанию создаются черновиками.
- Проверка привязана к администратору на 30 минут. Перед записью сервер проверяет изменения на сайте, включая остатки после оформления заказа. Один файл применяется целиком, повтор применения не создаёт дублей.

Руководство: [редактор страниц и перенос данных](https://github.com/maxx52/nova-engine/blob/main/docs/PAGE_EDITOR_AND_TRANSFER.md).

Предпросмотр показывает заголовок, текст и блоки, без шапки, подвала и пользовательского шаблона темы. Файлы изображений и формы переносятся отдельно. Заказы, ключи и пользователи админки не включены в экспорт. Для полного восстановления используйте резервные копии.
