# NOVA Engine 0.21.0 — обновления и резервные копии

- Раздел «Обновления и копии»: текущая версия, стабильные GitHub Releases, описание изменений и журнал операций.
- Установка согласованных версий админки, API и витрины через отдельную локальную службу на Linux VDS с systemd. Веб-приложение продолжает работать без root.
- Проверка формата релиза, SHA-256, версии Node.js, минимальной исходной версии, протокола менеджера и API тем до переключения. API тем остаётся версии 1.
- Полная резервная копия PostgreSQL, uploads, кода с зависимостями, публичных файлов и серверного env-файла. Проверка восстановления во временной базе и проверка архивов.
- Ежедневное расписание, срок хранения 7/14/30 дней, сохранение двух последних завершённых копий.
- Копия перед обновлением и восстановлением; автоматический откат при сбое запуска и восстановление прерванной операции при перезапуске службы.
- Без подключённой службы доступна проверка релизов; установка выполняется администратором хостинга. Docker-установщик не подключает привилегированную службу автоматически.

Обновление рассчитано на NOVA 0.20.0+. Нужны Node.js 22.12+ и Python 3.11+ для менеджера. Служба первой версии поддерживает native-развёртывание API через systemd и PostgreSQL 17 в локальном Docker; это схема нашего VDS. Для другого размещения нужно адаптировать развёртывание администратором сервера.

Копии содержат секреты, остаются на VDS и через браузер не выдаются. Для защиты от полной потери сервера настройте отдельное защищённое внешнее хранение. При восстановлении заменяются данные после даты выбранной копии; перед этим сохраняется текущее состояние.

Подробности: `docs/UPDATES.md`. Оформление, товары и пользовательские темы не изменяются при установке версии 0.21.0.
