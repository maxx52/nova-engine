# NOVA Engine 0.21.1 — запуск подготовки обновления на защищённом VDS

Исправление к 0.21.0: зависимости и проверка sharp готовятся в отдельной временной systemd-службе от пользователя приложения. Защищённому менеджеру не требуется самостоятельно переключать UID. У временной службы ограничены память, CPU, время работы и запись в файловую систему; потомки завершаются вместе с её cgroup.

Сохраняются проверка SHA-256, повторная сверка исходных файлов, полная копия перед переключением, проверка восстановления и автоматический откат. Обновление доступно с 0.20.0; API тем и протокол менеджера остаются версии 1.

**Для администратора сервера:** сам менеджер намеренно не заменяется пакетом сайта. Обновите `/usr/local/lib/nova-updater/agent.py` из проверенного кода 0.21.1 и перезапустите службу до запуска установки. Ветка 0.21.0 уже опубликована и не переписывается.

Предыдущие возможности: [NOVA 0.21.0](https://github.com/maxx52/nova-engine/releases/tag/v0.21.0). Руководство: `docs/UPDATES.md`.
