# NOVA Engine 0.28.0

Добавлен личный кабинет покупателя по адресу `/account`:

- вход по одноразовому коду на email через настроенный SMTP, включая профиль 1Gb.ru;
- имя и телефон, сохранённые адреса и основной адрес при оформлении;
- история собственных заказов, состав, статусы оплаты и доставки;
- повтор заказа с проверкой актуальных цен, остатков и точных вариантов;
- сохранение корзины при перезагрузке вкладки;
- отдельные покупательские сессии, защита изменений от CSRF, выход со всех устройств и постоянные ограничения попыток входа.

Гостевые заказы не присоединяются по совпадению телефона или email. Гостевое оформление доступно и без SMTP. Кабинет исключён из индексации и аналитики; приватные данные не передаются темам и редактору кода.

После обновления настройте email-доставку в разделе форм. Для собственной темы добавьте ссылку `/account`. Если раньше у контентной страницы был slug `account`, измените его перед обновлением. Миграции базы применяются автоматически; перед установкой нужна полная резервная копия.

Инструкция: [Личный кабинет покупателя](../CUSTOMER_ACCOUNTS.md).
